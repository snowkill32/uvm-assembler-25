# Ассемблер УВМ. Вариант 25

Практическая работа по конфигурационному управлению. Ассемблер написан на Python.

## Синтаксис

Исходная программа хранится в текстовом файле, например `program.asm`.
Каждая команда занимает одну строку. Адреса, константы и смещения записываются
десятичными числами. Запись `mem[545]` означает ячейку памяти с адресом `545`.
Знак `=` означает запись результата из правой части в ячейку, указанную слева.

| Команда | Пример | Действие |
| --- | --- | --- |
| Загрузка константы | `mem[545] = 215` | Записать число `215` в ячейку `545`. |
| Чтение из памяти | `mem[690] = mem[mem[711] + 26]` | Взять адрес из ячейки `711`, прибавить `26`, прочитать значение по полученному адресу и сохранить его в ячейке `690`. |
| Запись в память | `mem[mem[37]] = mem[276]` | Взять значение из ячейки `276` и записать его по адресу, который хранится в ячейке `37`. |
| Знак числа | `mem[mem[263]] = sgn(mem[283])` | Вычислить знак числа из ячейки `283` и записать его по адресу, который хранится в ячейке `263`. |

`sgn` возвращает `-1` для отрицательного числа, `0` для нуля и `1`
для положительного числа.

## Запуск

Из папки проекта выполни команду ниже.

```powershell
python src/assembler.py program.asm program.bin --test
```

- `program.asm` — путь к исходной программе.
- `program.bin` — путь к выходному двоичному файлу.
- `--test` — необязательный флаг, который включает тестовый режим.

Скрипт читает исходный файл и разбирает команды в список кортежей.
Например, команда `mem[545] = 215` даёт кортеж `(6, 545, 215)`.
С флагом `--test` скрипт печатает поля каждой команды на отдельной строке.
Для этого примера вывод будет `A=6, B=545, C=215`.
Справка доступна через `python src/assembler.py --help`.
В Windows ту же команду можно запустить через `.\run.bat`, передав ей
те же аргументы.

## Функции

- `parse_line` разбирает одну команду и возвращает кортеж её полей.
- `parse_program` читает файл и собирает список команд.
- `main` принимает аргументы и печатает поля команд в тестовом режиме.
