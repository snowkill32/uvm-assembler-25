# Ассемблер и интерпретатор УВМ. Вариант 25

Практическая работа по конфигурационному управлению. Проект написан на Python.

## Синтаксис

Исходная программа хранится в текстовом файле, например `program.asm`.
Каждая команда занимает одну строку. Адреса, константы и смещения записываются
десятичными числами. Запись `mem[545]` означает ячейку памяти с адресом `545`.
Знак `=` означает запись результата из правой части в ячейку, указанную слева.

| Команда | Пример | Действие |
| --- | --- | --- |
| Загрузка константы | `mem[545] = 215` | Записать число `215` в ячейку `545`. |
| Чтение из памяти | `mem[690] = mem[mem[711] + 26]` | Взять адрес из ячейки `711`, прибавить `26`, прочитать значение по полученному адресу и сохранить его в ячейке `690`. |
| Запись в память | `mem[mem[37]] = mem[276]` | Взять значение из ячейки `276` и записать его по адресу, который хранится в ячейке `37`. |
| Знак числа | `mem[mem[263]] = sgn(mem[283])` | Вычислить знак числа из ячейки `283` и записать его по адресу, который хранится в ячейке `263`. |

`sgn` возвращает `-1` для отрицательного числа, `0` для нуля и `1`
для положительного числа.

## Запуск

Из папки проекта выполни команду ниже.

```powershell
python src/assembler.py program.asm program.bin --test
```

- `program.asm` — путь к исходной программе.
- `program.bin` — путь к выходному двоичному файлу.
- `--test` — необязательный флаг для вывода байтов каждой команды.

Скрипт читает исходный файл, превращает команды в байты и записывает их
в выходной файл. В обоих режимах он выводит число команд. С флагом
`--test` он также печатает байты каждой команды на отдельной строке.
Справка доступна через `python src/assembler.py --help`.
В Windows ту же команду можно запустить через `.\run.bat`, передав ей
те же аргументы.

Интерпретатор принимает путь к бинарной программе, путь к XML-дампу
и включительный диапазон адресов в формате `START:END`. Он загружает байты
программы в общую память с адреса 0, выполняет команды и сохраняет дамп.
Ячейки, в которые ещё ничего не записали, читаются как 0.

## Функции

- `parse_line` разбирает одну команду и возвращает кортеж её полей.
- `parse_program` читает файл и собирает список команд.
- `encode_load` упаковывает поля команды и возвращает её байты.
- `main` принимает аргументы, записывает двоичный файл и выводит результат.
- `parse_address_range` проверяет диапазон адресов для дампа.
- `write_memory_dump` сохраняет значения ячеек в XML.

## Проверка этапа 3

Пример копирует значения из ячеек 512–514 в ячейки 600–602.

```powershell
python src/assembler.py tests/copy_array.asm copy.bin
python src/interpreter.py copy.bin copy.xml 600:602
```

Для второго элемента команда чтения берёт адрес 512 из ячейки 700,
прибавляет смещение 1 и сохраняет прочитанное значение 42 в ячейке 702.
Затем команда записи берёт из ячейки 701 адрес 601 и кладёт туда число 42.

В `copy.xml` получится:

```xml
<?xml version="1.0" encoding="utf-8"?>
<memory>
  <cell address="600">12</cell>
  <cell address="601">42</cell>
  <cell address="602">9</cell>
</memory>
```

Команда `sgn` выполняется на этапе 4.
